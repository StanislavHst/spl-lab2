# Лабораторна робота 2

Проєкт містить лексичний аналізатор для частини 2а та синтаксичний аналізатор методом рекурсивного спуску для частини 2б.

## Файли

- `Lab2a` — читання речень і запис знайдених лексем у `output.txt` та `tokens.txt`.
- `Lab2b` — перевірка речень двома способами: з `input.txt` або з `Lab2a/tokens.txt`.
- `Lexer.h` — спільна функція отримання лексем.
- `Laboratorna_2a_variant_15.docx` і `Laboratorna_2b_variant_15.docx` — звіти.
- `syntax_diagram.png` — синтаксична діаграма.

## Запуск

Відкрити `SPL_Lab2.sln` у Visual Studio або Rider та зібрати проєкт.

Для 2а запустити `Lab2a`. Вхідні речення знаходяться у `Lab2a/input.txt`.

Для 2б запустити `Lab2b` і вибрати режим `1` для читання речень або `2` для читання лексем із файлу, створеного частиною 2а.
